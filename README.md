# Namaz Vakitleri

Android için kişisel namaz vakitleri uygulaması (Türkçe / Deutsch).

- Diyanet yöntemiyle telefonda hesaplama (internet gerekmez)
- Sonraki vakte geri sayım, gün gün gezinme, aylık tablo
- Vakit bildirimleri, isteğe bağlı ezan sesi (kendi mp3 dosyanız), "x dk önce" hatırlatma
- Kıble pusulası
- Her vakit için dakika düzeltme

APK: https://github.com/42zengibar42-cell/namaz-vakitleri/releases/latest/download/Namaz-Vakitleri.apk
